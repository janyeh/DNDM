## 變更記錄 #003 - 損失穩定性優化
**日期**: 2024-07-13  
**變更類型**: 性能優化 + 穩定性改進  
**優先級**: 高  
**狀態**: 已完成  

### 問題分析
從訓練log發現：
- 損失縮放過於保守 (`loss_scale_threshold=100, loss_scale_factor=0.01`)
- 真實損失值很大 (`loss_dehaze: 175396832.0000`) 但被強制縮放到100
- ETA仍然長達12天，比預期的1.5-2.5天慢很多
- 需要進一步優化訓練速度和穩定性

### 變更內容
#### 🚀 性能優化
- **batch_size**: 4 → 8 (再次提升訓練效率)
- **learning_rate**: 0.0002 → 0.0003 (加速收斂)

#### 🛡️ 穩定性改進
- **loss_scale_threshold**: 100.0 → 1000.0 (減少過度縮放)
- **loss_scale_factor**: 0.01 → 0.1 (降低縮放強度)
- **gradient_clip_norm**: 1.0 → 2.0 (增加梯度裁剪範圍)
- **tensor_value_clip**: (-1.0, 1.0) → (-2.0, 2.0) (放寬張量值範圍)
- **enable_anomaly_detection**: True → False (提高訓練速度)

#### 🎯 損失權重平衡
- **dehaze_loss**: 10.0 → 1.0 (避免損失主導)
- **dc_loss**: 0.01 → 0.001 (減少暗通道損失影響)

### 相關文件
- `Code/train.py` - 更新所有穩定性和性能配置參數

### 預期效果
- **訓練時間**: 12天 → 3-5天 (60-75%減少)
- **損失穩定性**: 減少過度縮放，讓模型正常學習
- **收斂速度**: 更快達到性能指標
- **GPU效率**: 更高的批次大小提升硬體利用率

### 實際效果 (待驗證)
> 📋 **等待新訓練結果**
> - [ ] ETA變化 (目標: 12天 → 3-5天)
> - [ ] loss_G數值變化 (目標: 降低過度縮放頻率)
> - [ ] 訓練穩定性檢查
> - [ ] GPU記憶體使用監控 (batch_size=8)
> - [ ] 個別損失組件平衡性

## 變更記錄 #005 - 提升 SSIM 與學習率排程優化
**日期**: 2025-08-12  
**變更類型**: 配置優化 + 損失設計  
**優先級**: 高  
**狀態**: 已完成  

### 背景
上一輪訓練最終指標 PSNR=21.94、SSIM=0.579，顯示結構相似性偏低，且學習率在後段衰減至 0 造成學習停滯；同時 `loss_DC_A`、`loss_Lab` 相對偏大，抑制了細節與結構學習。

### 變更內容
- **延長訓練**: `TOTAL_EPOCHS` 20 → 120（避免早停，爭取更高 SSIM）
- **學習率策略**:
  - `CosineAnnealingLR` 加入 `eta_min=1e-6`，避免 LR 掉為 0
  - `T_max=TOTAL_EPOCHS`，與總 epochs 對齊
  - 新增 `warmup_epochs=5`，前 5 個 epoch 線性升溫
  - `learning_rate=2e-4`、`weight_decay=1e-6`
- **損失權重重平衡**:
  - `perceptual_loss` 0.04 → 0.07（加強紋理/結構）
  - 新增 `MS-SSIM` 損失，權重 `msssim_loss=0.2`
  - `dc_loss` 降至 0.02、`lab_loss` 設為 0.05（避免對比/色彩過強）
  - 啟用輕量 `tv_loss=2e-6`
  - `CAP` 仍不納入總損失（僅日誌）
- **最佳模型保存**:
  - 以驗證集 SSIM 為主、PSNR 為次保存 `output/best_*.pth`
- **指標計算**:
  - 驗證階段採用 torch 計算 PSNR，並以 `MS-SSIM` 作為 SSIM 指標
- **套件**:
  - 新增 `pytorch-msssim==0.2.1` 到 `Code/pip-req.txt`

### 相關文件
- `Code/train.py`
  - 調整 `TOTAL_EPOCHS`、`OPTIMIZER_CONFIG`、`LOSS_WEIGHTS`
  - 加入 warmup、`eta_min`、`MS-SSIM`、輕量 TV loss
  - 新增最佳模型保存邏輯
- `Code/pip-req.txt`
  - 新增 `pytorch-msssim` 依賴

- **後期不再停學**（LR 不會趨近 0）
